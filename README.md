# Crochet Row Counter

A row counter for crochet that works on your phone (knitting too). You don't need an account and there are no ads. Everything is saved on your device.

## What it does

There are four tabs along the bottom, like a regular phone app:

- **Counter:** a big + button for each row, plus − and Undo for accidental taps. It also has a repeat counter and a timer for the project.
- **Projects:** your crochet projects. Tap **+** to start a new one, tap a project to open it, and tap **⋯** to rename or delete it.
- **Notes:** pattern notes and row reminders. Type lines like `12: change to blue` and you get a pop-up when you reach that row.
- **Settings:** total rows goal, rows per repeat, rows or rounds, vibration, keeping the screen on, and backup/restore.

**iPhone Duo / wide screens:** when you unfold an iPhone Duo (or use an iPad or turn your phone sideways), the app switches to two columns. Your pattern notes sit next to the counter, so you can read the pattern while you count. On the outer screen it works like a normal phone.

Everything else:
- Each project keeps its own counts, notes, reminders and time
- Works offline and can go on your home screen
- Keyboard: Space / Enter / ↑ adds a row, ↓ takes one away, Z undoes

If your old twister row counter is hosted on the same GitHub Pages site, this app picks up those projects the first time you open it.

## Put it online with GitHub Pages

1. Merge this branch into `main`, or select this branch in step 3.
2. In the repo, go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**. Pick the branch and `/ (root)`, then click Save.
4. About a minute later it will be live at `https://<your-username>.github.io/<repo-name>/`.

To make it open like a normal app, open the link on your phone and tap **Share → Add to Home Screen** on iPhone or **⋮ → Install app** on Android.

## Run it locally

Open `index.html` in a browser. Offline mode only works when the app is served over http(s).
